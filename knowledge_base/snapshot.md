## Алгоритм снэпшотинга volume'ов для Docker

Для каждого volume в инфраструктуре создаётся временный вспомогательный контейнер `volume_archiver`, который:

1. Монтирует целевой volume в режиме `ro` (`read-only` — snapshot не должен мутировать данные).
2. Монтирует host-директорию snapshot'а в режиме rw как точку вывода архива.
3. Выполняет `tar` внутри себя, архивируя содержимое volume в файл на host-директории.
4. Автоматически удаляется после завершения (`remove=True` / `--rm`)

## Алгоритм снэпшотинга node'ы для Docker

1. Делаем коммит контейнера
2. Сохраняем образ из коммита в отдельный `.tar`

## Общие данные

Конфигурация и метаинформация хранится в `.json`-файлах для каждой сущности

Сам снэпшот хранится в `.tar`-файле в указанном пользователем пути или в папке `~/pg-polygon-orchestr/snapshots/`

Метаинформация снэпшота хранится в `meta.json`

Построение инфраструктуры из снэпшота предполагает создание всех сетей, томов, нод, а также возврат объекта Deployer'а
