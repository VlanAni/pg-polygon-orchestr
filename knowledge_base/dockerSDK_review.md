# Возможности
#### Создание клиента

Можно создать клиента с параметрами конфигурации из переменных окружения функцией `from_env()` - она возвращает объект класса `DockerClient`
#### Создание конфигов

Можно управлять конфигами контейнеров через сервер с помощью методов `client.configs`
#### Управление контейнерами

Можно запускать контейнеры, останавливать контейнеры, получать список контейнеров

Методы по управлению контейнерами доступны из `client.containers`
#### Управление образами

Можно создавать образы, скачивать образы, получать список доступных образов, удалять образы

Методы доступны из `client.images`
#### Управление сетью

Можно создавать сети, удалять сети, получать сеть по её айдишнику, получать список сетей, подключать контейнеры к сети, обновлять атрибуты сети, удалять сеть

Доступны из `cleint.networks`
#### Кластеры, ноды и секреты

Есть также функционал для управления: 
- кластерами (режим `Swarm`, создание кластера, подключить контейнер к кластеру, обновлять конфигурации) - `client.swarm`
- нодами в кластере - `client.nodes`. **Важно**: методы можно юзать только после создания кластера
- *секретами* для конфиденциальных данных приложения (создание, получение по айдишнику, список секретов) - `client.secrets`
- *сервисами* в кластере, которые описывают *желаемое состояние системы* (создание, получение по айдишнику, получение списка сервисов, посмотреть список задач, управление отдельным сервисом) - `client.services`
#### Volumes

Для томов доступны стандартные операции: создание, получить по айдишнику, удалить, обновить атрибуты и данные
#### Низкоуровневое API

Низкоуровневое API позволяет напрямую обращаться к Docker Engine и управлять большим количеством параметров 

Все функции мапятся в REST API Docker'а 

Класс - `APIClient`
#### TLS

Можно настраивать TSL подключение клиента к движку Docker'а с помощью класса `TLSConfig`
