Библиотека поддерживает привязку томов к докер контейнерам

В конфиге можно указать драйвер для тома, опции для этого драйвера (работают только для DockerDeployer'а)

Обновлять конфигурацию тома после его создание Docker не позволяет

Ограничение размера Volume'а доступно только с драйвером tmpfs, когда том хранится в оперативной памяти
